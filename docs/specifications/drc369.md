# DRC-369: Dynamic NFT Standard

The Demiurge Resource Contract 369 standard for stateful, physics-enabled NFTs.

---

## Overview

DRC-369 extends traditional NFTs with:
- **Dynamic State** - NFTs can store and update data
- **Physics Properties** - Game engine integration (UE5, Unity)
- **Nested Composition** - NFTs can contain other NFTs
- **Soulbound Option** - Non-transferable tokens
- **CVP Protection** - Security through code mutation

---

## Token Structure

```rust
pub struct Drc369Token {
    /// Unique token identifier (32 bytes)
    pub id: [u8; 32],
    
    /// Current owner address
    pub owner: [u8; 32],
    
    /// Token metadata URI
    pub token_uri: Option<String>,
    
    /// Whether token is non-transferable
    pub is_soulbound: bool,
    
    /// Parent token ID (for nesting)
    pub parent_token_id: Option<[u8; 32]>,
    
    /// CVP-protected contract ID
    pub cvp_contract_id: Option<[u8; 32]>,
    
    /// Creation timestamp
    pub created_at: u64,
    
    /// Last modification timestamp
    pub updated_at: u64,
}
```

## Dynamic State

NFTs can store arbitrary key-value data:

```rust
// Set state
drc369.set_state(token_id, "kills", "42");
drc369.set_state(token_id, "level", "5");
drc369.set_state(token_id, "equipped_weapon", "sword_001");

// Get state
let kills = drc369.get_state(token_id, "kills"); // "42"
```

### State Categories

| Category | Examples | Use Case |
|----------|----------|----------|
| Stats | kills, deaths, wins | Game progression |
| Equipment | weapon, armor, pet | Inventory management |
| Metadata | name, description | Display information |
| History | previous_owners, transfers | Provenance tracking |

## Physics Properties

DRC-369 tokens can include physics metadata for game engines:

```rust
pub struct PhysicsProperties {
    /// Mass in kilograms
    pub mass: f32,
    
    /// Coefficient of friction (0-1)
    pub friction: f32,
    
    /// Bounciness coefficient (0-1)
    pub restitution: f32,
    
    /// Linear damping (air resistance)
    pub linear_damping: f32,
    
    /// Angular damping (rotational resistance)
    pub angular_damping: f32,
    
    /// Collision shape type
    pub collision_shape: CollisionShape,
    
    /// Whether object is static (immovable)
    pub is_static: bool,
    
    /// Whether object is affected by gravity
    pub gravity_enabled: bool,
}

pub enum CollisionShape {
    Box { half_extents: [f32; 3] },
    Sphere { radius: f32 },
    Capsule { radius: f32, half_height: f32 },
    Mesh { vertices: Vec<[f32; 3]> },
}
```

### Setting Physics

```bash
# RPC call
curl -X POST https://rpc.demiurge.cloud:9944 \
  -H "Content-Type: application/json" \
  -d '{
    "jsonrpc": "2.0",
    "id": 1,
    "method": "drc369_setPhysics",
    "params": [
      "TOKEN_ID_HEX",
      "{\"mass\":10.0,\"friction\":0.5,\"restitution\":0.3}",
      "SIGNATURE_HEX"
    ]
  }'
```

### Querying Physics

```bash
curl -X POST https://rpc.demiurge.cloud:9944 \
  -d '{"jsonrpc":"2.0","id":1,"method":"drc369_getPhysics","params":["TOKEN_ID_HEX"]}'
```

Response:
```json
{
  "result": {
    "token_id": "0x...",
    "has_physics": true,
    "physics": {
      "mass": 10.0,
      "friction": 0.5,
      "restitution": 0.3
    },
    "simulation_ready": true
  }
}
```

## Nested Composition

NFTs can be nested inside other NFTs:

```
Spaceship (NFT)
├── Engine (NFT)
├── Weapon System (NFT)
│   ├── Laser Cannon (NFT)
│   └── Missile Launcher (NFT)
└── Cargo Hold (NFT)
    ├── Resource Crate (NFT)
    └── Loot Box (NFT)
```

### API

```rust
// Attach NFT to parent
drc369.attach(child_token_id, parent_token_id);

// Detach NFT from parent
drc369.detach(child_token_id);

// Get children
let children = drc369.get_children(parent_token_id);
```

## Soulbound Tokens

Non-transferable tokens for achievements, credentials, etc:

```rust
// Mint soulbound token
drc369.mint(owner, token_uri, is_soulbound: true);

// Transfer will fail
drc369.transfer(soulbound_token, new_owner); // Error: Token is soulbound
```

## Royalties

DRC-369 supports automatic royalty distribution on transfers:

```rust
pub struct RoyaltyConfig {
    /// Royalty recipient address
    pub recipient: [u8; 32],
    
    /// Royalty percentage (basis points, 100 = 1%)
    pub percentage_bps: u16,
}

// Set royalties (creator only)
drc369.set_royalties(token_id, RoyaltyConfig {
    recipient: creator_address,
    percentage_bps: 500, // 5%
});
```

On transfer, royalties are automatically deducted and sent to the recipient.

## RPC Methods

### Query Methods

| Method | Parameters | Returns |
|--------|------------|---------|
| `drc369_totalSupply` | none | Total minted |
| `drc369_balanceOf` | owner | NFT count |
| `drc369_ownerOf` | token_id | Owner address |
| `drc369_tokenURI` | token_id | Metadata URI |
| `drc369_getTokenInfo` | token_id | Full token info |
| `drc369_isSoulbound` | token_id | Boolean |
| `drc369_hasPhysics` | token_id | Boolean |
| `drc369_getPhysics` | token_id | Physics properties |
| `drc369_getDynamicState` | token_id, key | State value |
| `drc369_getStateBatch` | token_id, keys[] | Multiple values |

### Write Methods

| Method | Parameters | Description |
|--------|------------|-------------|
| `drc369_mint` | to, uri, soulbound | Create NFT |
| `drc369_transfer` | token_id, to | Transfer ownership |
| `drc369_setPhysics` | token_id, physics, sig | Set physics |
| `drc369_setState` | token_id, key, value, sig | Update state |

## SDK Usage

### TypeScript

```typescript
import { DRC369Client } from '@demiurge/drc369-sdk';

const client = new DRC369Client({
  rpcUrl: 'https://rpc.demiurge.cloud:9944'
});

// Query NFTs
const balance = await client.balanceOf(ownerAddress);
const tokenInfo = await client.getTokenInfo(tokenId);
const physics = await client.getPhysics(tokenId);

// Mint NFT (requires wallet)
const result = await client.mint({
  to: recipientAddress,
  tokenUri: 'https://example.com/metadata.json',
  physics: {
    mass: 10,
    friction: 0.5
  },
  wallet: wallet
});
```

### React Hooks

```typescript
import { useDRC369, useTokenInfo, usePhysics } from '@demiurge/drc369-sdk/react';

function NFTDisplay({ tokenId }) {
  const { data: info, isLoading } = useTokenInfo(tokenId);
  const { data: physics } = usePhysics(tokenId);
  
  if (isLoading) return <Loading />;
  
  return (
    <div>
      <h1>Owner: {info.owner}</h1>
      <p>Mass: {physics?.mass} kg</p>
    </div>
  );
}
```

## Game Engine Integration

### Unreal Engine 5

```cpp
#include "DemiurgeSDK.h"

// Load NFT physics
FDemiurgePhysics Physics = DemiurgeClient->GetPhysics(TokenId);

// Apply to UE5 actor
UPrimitiveComponent* Comp = Actor->FindComponentByClass<UPrimitiveComponent>();
Comp->SetMassOverrideInKg(NAME_None, Physics.Mass);
Comp->SetLinearDamping(Physics.LinearDamping);
Comp->SetAngularDamping(Physics.AngularDamping);
```

### Unity

```csharp
using Demiurge.SDK;

// Load NFT physics
var physics = await demiurgeClient.GetPhysics(tokenId);

// Apply to Rigidbody
var rb = gameObject.GetComponent<Rigidbody>();
rb.mass = physics.mass;
rb.drag = physics.linearDamping;
rb.angularDrag = physics.angularDamping;
```

## Best Practices

1. **Use meaningful state keys** - `kills` not `k`
2. **Validate physics values** - Mass > 0, friction 0-1
3. **Store large data off-chain** - Use `token_uri` for images
4. **Consider gas costs** - Batch state updates when possible
5. **Document your schema** - Define expected state keys
